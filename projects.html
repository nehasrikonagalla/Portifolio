🛡️ SafeRide – QR-Based Vehicle Emergency Contact System

Live Demo: https://emergency-qr-lake.vercel.app/

Developed a QR-based emergency contact system using HTML, CSS, and JavaScript to help accident victims receive timely assistance.

  • Enables bystanders to scan a QR code attached to a vehicle and access two emergency contacts.
  • Helps bystanders quickly inform the victim’s emergency contacts during accidents or emergencies.

🔐 Crypta – Secure Message Encryption and Decryption System

Live Demo: https://nehasrikonagalla.github.io/Crypta_encrypter/

Developed a secure messaging web application using HTML, CSS, and JavaScript that allows users to encrypt and decrypt messages using a secret code.

  • Sender Page: Allows users to enter a secret code and message, then encrypt the message before sharing it.
  • Receiver Page: Allows the receiver to enter the matching secret code to decrypt and read the message.
